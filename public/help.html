На телефоне используй экранные кнопки. В горизонтальной ориентации лучше видны площадки и редактор. В настройках можно изменить громкость, уменьшить эффекты и включить полный экран, если браузер его поддерживает.

Как проходить терминалы

  1. Подойди к светящемуся терминалу и нажми E.
  2. Прочитай короткое задание. Менять можно только выделенные значения и операторы — писать программу с нуля не нужно.
  3. Выбери исправление и нажми кнопку применения. Ошибка даст объяснение; попробовать снова можно сразу.
  4. Проверь результат в мире: меняется движение, отключается барьер, появляется мост или открывается проход.
  5. Найди остальные два терминала этого сектора. Для выхода нужны все три исправления; в некоторых секторах — ещё ключи, предохранители и рубильник.

У каждого терминала две подсказки. За сектор можно использовать до шести; счётчик ошибок и подсказок общий для трёх задач. В паузе и редакторе игра не движется.

Что происходит при столкновении

Монстр начинает текущий сектор заново. После короткого экрана поражения все исправления и предметы этой попытки теряются, контрольные точки и рубильник сбрасываются. Таймер, ошибки и подсказки начинают новую попытку. Возвращаться к первому уровню игры не нужно: завершённые сектора, рекорды и открытые уровни сохраняются.

Падение, шипы и статические опасности возвращают к контрольной точке и сохраняют текущие исправления, предметы и счётчики. Монстров нужно обходить: наблюдай за их патрулём и выбирай момент для прыжка. Кнопка R тоже полностью перезапускает текущий сектор.

За что дают звёзды

  • 3 звезды: ни одной ошибки и подсказки.
  • 2 звезды: не больше двух ошибок и одной подсказки.
  • 1 звезда: остальные завершённые попытки.

Результат считается за весь сектор. Время хранится отдельно. Повторное прохождение не ухудшает уже полученные лучшие показатели.

Где хранится мой прогресс

Эта опубликованная версия подключена к Supabase. Посмотри на статус сохранения в игре:

  • «Прогресс сохранён в облаке» — запись подтверждена Supabase.
  • «Прогресс сохранён локально» — результат находится в этом браузере.
  • «Синхронизация...» — игра отправляет ожидающие результаты.

Вход анонимный: почта и пароль не нужны. Каждый игрок получает собственный профиль. При временной недоступности облака можно продолжать играть; результаты сохраняются локально и отправляются после восстановления соединения.

Не очищай данные сайта, если хочешь сохранить доступ к профилю. Другой браузер, приватное окно или устройство могут получить новую анонимную сессию. Перенос между устройствами и восстановление после удаления сессии не гарантируются.

Запустить у себя

  1. Скачай и распакуй ZIP.
  2. Установи Node.js 22.12 или новее с nodejs.org.
  3. Открой терминал в папке, где лежит package.json, и выполни по очереди:
npm install
npm run dev

Открой адрес из терминала, обычно http://localhost:5173. Оставь терминал открытым, пока играешь. Остановка сервера — Ctrl + C.

Исходная копия без своих настроек Supabase работает в локальном режиме. Все изображения уже включены. Двойной щелчок по index.html не заменяет запуск сервера.

Подключить облако к своей копии

Для независимой копии создай собственный проект Supabase. Это не требуется для обычной игры по предоставленной ссылке.

  1. Создай проект на supabase.com.
  2. В SQL Editor вставь содержимое supabase/setup.sql из архива и нажми Run. Этот файл создаёт таблицы и правила доступа.
  3. В Authentication → Sign In / Providers включи Anonymous Sign-Ins.
  4. В настройках проекта возьми Project URL и публичный publishable key с началом sb_publishable_.
  5. Рядом с package.json создай файл .env по образцу .env.example и заполни своими значениями:
VITE_SUPABASE_URL=https://YOUR-PROJECT.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_YOUR_PUBLIC_KEY

Здесь показан образец, его нужно заменить. Секретный ключ игре не нужен и в браузере использоваться не должен.

  1. Перезапусти сервер: Ctrl + C, затем npm run dev.
  2. Пройди сектор и дождись статуса облачного сохранения. В Table Editor проверь profiles, level_progress и runs.

Обновляешь базу предыдущей версии? Выполни supabase/upgrade-three-puzzles.sql либо весь новый setup.sql. Новая версия сохраняет до шести подсказок за сектор; старое ограничение допускало только две.

Разместить свою копию на Vercel

Загрузи исходники в свой GitHub и импортируй репозиторий в Vercel. Выбери Vite, команду сборки npm run build и папку результата dist. Для облака добавь две переменные Supabase в Environment Variables до сборки. После изменения переменных выполни новый Deploy.

Подробные шаги запуска, публикации и проверки доступа к данным находятся в README архива. Тесты и ограничения текущей поставки — в TEST-REPORT. Результаты рассчитывает браузер; защищённый от читерства рейтинг не заявлен.
