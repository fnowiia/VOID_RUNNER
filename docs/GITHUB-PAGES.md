# Публикация GitHub Pages

Репозиторий: https://github.com/fnowiia/VOID_RUNNER
Сайт: https://fnowiia.github.io/VOID_RUNNER/

Settings → Pages → Build and deployment → Deploy from a branch → gh-pages → / (root).

Сборка рассчитана на размещение как в корне домена, так и в папке `/VOID_RUNNER/`. Относительные пути не требуют ручной правки.

`main` — исходники; `gh-pages` — готовые файлы. Файл `.nojekyll` отключает ненужную обработку Jekyll. Базу Supabase заново создавать не требуется.

Доступность нужно проверять из сети игрока. Публичная публикация не гарантирует отсутствие блокировок конкретного провайдера. Анонимная сессия на новом домене отдельная от прежнего сайта.
