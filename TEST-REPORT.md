# Проверка ERROR 404 v2 — Escape the System

Дата: 14 ноября 2026 года.

## Реализованная версия

Пять карт размером до 4160×1024, 15 разных заданий (по три терминала в каждом секторе), вертикальные маршруты и физические ворота. Строительство трёх секций моста, трёх опор подъёмника и четырёх ступеней лестницы. Есть отключаемые поля и пульсирующие лазеры, патрулирующие жуки и летающие наблюдатели. Столкновение с монстром перезапускает текущий сектор; падение возвращает к контрольной точке с сохранением текущих исправлений.

## Выполненные проверки

- `npm run assets`: воспроизводимая генерация PNG, включая новый лист монстров 384×32 с 12 кадрами. Предыдущие изображения сохранены побайтово. Обложка меню включена отдельно и не перезаписывается генератором.
- `npm test`: **84 теста проходят**. Проверены все 15 головоломок и предлагаемые комбинации ответов, безопасный отказ от неизвестных/исполняемых значений, подсказки 0–6, награды, восстановление очереди, вкладки и смена владельца. 23 теста геометрии учитывают тело персонажа, потолки, ворота, порядок исправлений, обязательные постройки и ресурсы, контрольные точки и границы патрулей.
- `npm run build`: успешная production-сборка Vite; импорты, анимации и изображения загружаются.
- Мобильный Chromium 844×390: проверены настоящее экранное движение и прыжок, первый терминал из трёх, HUD 1/3, пауза и остановка таймера, сохранение настроек. В 390×844 проверена неблокирующая подсказка о повороте. Кнопки размещены в отдельной полосе под Canvas.
- **Сквозной браузерный прогон прошёл:** все пять новых секторов, все 15 разных терминалов, настоящие ресурсы, ворота и выходы, финальная сцена и восстановление пяти завершённых уровней после перезагрузки. Отдельная проверка столкновения с настоящим патрулирующим монстром в третьем секторе после двух исправлений и сбора ключа подтвердила экран гибели и полный сброс текущих исправлений, ключей, ошибок и подсказок. Сектор остался тем же, счётчик гибели увеличился, завершённые уровни сохранились.
- В успешных браузерных прогонах нет ошибок JavaScript, отсутствующих изображений и HTTP 404. Игровой сквозной прогон проверяет локальный резервный режим, блокируя только запросы Supabase; настоящий облачный API проверен отдельно ниже.

Отчёты: `docs/verification/browser-report.json` и `docs/verification/mobile-report.json`. Снимки меню, редактора, финала, гибели и мобильного интерфейса находятся рядом.

Браузерный сценарий управляет клавишами и разрешёнными полями редактора. Для ускорения он прокручивает настоящие кадры Phaser без отрисовки каждого кадра; физика, ворота, предметы и враги остаются игровыми. Материализация платформ ожидается до фактического включения коллайдеров. Телепортации и принудительная выдача победы не используются.

## Настоящий Supabase

Создан отдельный проект ERROR404 на бесплатном плане. Выполнен `supabase/setup.sql`: таблицы `profiles`, `level_progress`, `runs`, ограничения, триггер сохранения лучших результатов, явные права и RLS.

- Два независимых настоящих анонимных пользователя созданы через Auth после включения Anonymous Sign-Ins.
- **26 проверок реального REST API прошли**: собственные профили/история/прогресс сохраняются; чужие SELECT пусты, UPDATE не затрагивает строки, поддельный владелец блокируется; 6 подсказок допускаются, 7 отклоняются; история запрещает UPDATE/DELETE; повтор UUID не создаёт дубликат; поздний худший результат не ухудшает рекорды; посетитель без сессии не имеет доступа.
- Отдельный браузер с настоящим Supabase SDK: анонимный вход, ник, статус «Прогресс сохранён в облаке», запись результата через сервис сохранения, отсутствие ожидающих отправки и восстановление после перезагрузки. В этой интеграционной проверке результат передан сервису напрямую, а не получен прохождением карты; проверка проходимости выполняется отдельно.
- Дополнительно SQL выполнен в локальном PostgreSQL/PGlite: 14 групп проверок свежей схемы, повторной установки, обновления прежнего лимита подсказок, RLS и минимальных прав. Локальная модель `auth.uid()` не заменяет перечисленные выше реальные REST-проверки.

Доказательства без токенов: `docs/verification/supabase-live-report.json` и `docs/verification/browser-cloud-report.json`. В браузере и в сборке используется только публичный publishable key. Секретные административные ключи не применялись.

## Пределы проверки

Эмуляция Chromium не заменяет отдельную проверку физических Android/iOS и Safari. Устойчивые 60 FPS и время обучения новичка не измерялись. Результаты клиентской учебной игры не защищены от намеренной подмены. Анонимная сессия не обещает переноса между устройствами или восстановления после очистки данных браузера.
